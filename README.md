# aula-mobile-alert
Sistema acádemico de percepción computacional para la detección y análisis del uso de dispositivos móviles en aulas.

## Gestión de Datos

La estructura del dataset se organiza de la siguiente manera:
```text
data/
├── raw/
├── processed/
└── annotations/
```
Nota: Los datos pesados (imágenes y videos) no se almacenan directamente en este repositorio.
