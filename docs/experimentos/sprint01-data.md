# Sprint 01 - Preparación de Datos y Entorno

## Objetivo
Preparar la base del proyecto para la gestión del dataset, documentación y primeros procesos de validación.

## Actividades Realizadas
- Creación de la estructura del dataset (`data/raw`, `data/processed`, `data/annotations`).
- Documentación de cada directorio de datos con archivos `README.md`.
- Actualización de `.gitignore` para omitir datos pesados.
- Creación del script inicial de validación (`scripts/validate_dataset.py`).
- Configuración del entorno de desarrollo de Python.

## Resultado Real
La estructura inicial de datos y los scripts de validación están operativos y listos para recibir información.

## Problemas Encontrados
Ninguno en la preparación inicial.
