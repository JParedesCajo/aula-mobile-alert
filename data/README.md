# Dataset
Esta carpeta contiene los datos para el entrenamiento y validación de los modelos.

## Estructura
- `raw/`: Datos originales.
- `processed/`: Datos procesados.
- `annotations/`: Etiquetas/anotaciones.

## Consideraciones
- Clases iniciales: `person` y `cell phone`.
- No subir archivos pesados directamente al repositorio.
